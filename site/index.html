Mechatronics
from Scratch

Build the machines you use every day, starting from the maths. Circuits, motors, embedded C, control, robotics and ROS 2: you derive each idea by hand, code it from first principles, then break it in a live simulation.

Start lesson 1 See all 20 phases

Every lesson runs the same four steps

  1. Derive

    Write the physics by hand: the ODE, the transfer function, the Jacobian.

  2. Code

    Implement it from scratch in Python and NumPy, or bare-metal C when it runs on a microcontroller.

  3. Test

    Prove it works with a check you can rerun: a residual, a margin, a step response.

  4. Keep

    Save the artifact, then meet the professional tool it maps to: ngspice, KiCad, ROS 2, MuJoCo.

Break the machine

Each lab integrates real equations of motion in your browser. Switch a part off, add noise or kill a motor, and see what fails. Then open the lesson that explains why.

Educational approximations with illustrative parameters, not validated against specific hardware.

The course, phase by phase

Open a phase to see its lessons. Full lessons have an explanation, derivation, worked example, code, exercises and a quiz. The rest show their outline until they are written.
