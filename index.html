Break the machine

Each lab integrates the real equations of motion in your browser. Switch a part off, add noise, kill a motor, and watch exactly what fails. Then open the lesson that explains why.

Educational approximations: simplified models with illustrative parameters, not validated against specific hardware.

how this works

One loop, 352 times

  1. 01

    Derive

    Write the physics and the maths by hand: the ODE, the transfer function, the Jacobian, the Riccati equation.

  2. 02

    Code

    Implement it from scratch in Python/NumPy, or bare-metal C when it has to run on a microcontroller.

  3. 03

    Test

    Every lesson ships a test that proves it works: a residual, a margin, a step response, a logic-analyser trace.

  4. 04

    Keep

    Keep the artifact (plot, firmware, schematic, notebook), then meet the pro tool it maps to: ngspice, KiCad, python-control, ROS 2, MuJoCo, PlatformIO.

colophon

Free. Open. Yours.

The whole curriculum is plain markdown plus one curriculum.json, MIT licensed. No paywall, no signup, no tracking. Fork it, teach it, translate it. The labs run entirely in your browser; three.js is bundled locally and nothing loads from a CDN.

Course mappings marked "ETH" name real ETH Zurich course titles for orientation only; others are generic topics. This project is independent and not affiliated with or endorsed by ETH Zurich or any company. Simulations are educational approximations.

Source code and curriculum: github.com/andreolf/mechatronics-from-scratch. Issues and pull requests welcome.
