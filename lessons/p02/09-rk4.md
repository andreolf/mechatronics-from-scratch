## Sampling the slope more than once

Euler uses the slope at the start of the step. A better step averages slopes at several trial points inside the interval. A general two-stage method is

$$k_1 = f(x_k), \quad k_2 = f(x_k + a\,h\,k_1), \quad x_{k+1} = x_k + h(b_1 k_1 + b_2 k_2).$$

## Matching Taylor terms

The exact solution satisfies $x(t + h) = x + hf + \tfrac{h^2}{2}f'f + O(h^3)$, where $f' = \partial f/\partial x$. Expanding $k_2 = f + ahf'f + O(h^2)$, the method gives

$$x_{k+1} = x + h(b_1 + b_2)f + h^2\, b_2 a\, f'f + O(h^3).$$

Matching the two expansions term by term requires $b_1 + b_2 = 1$ and $b_2 a = \tfrac12$. Any solution gives a second-order method; $a = \tfrac12$, $b_1 = 0$, $b_2 = 1$ is the midpoint method. Pushing the same idea to four stages and matching through $h^4$ gives eight conditions, and the classical solution is

$$\begin{aligned} k_1 &= f(t, x), & k_2 &= f\big(t + \tfrac h2, x + \tfrac h2 k_1\big),\\ k_3 &= f\big(t + \tfrac h2, x + \tfrac h2 k_2\big), & k_4 &= f(t + h, x + hk_3), \end{aligned}$$

$$x_{k+1} = x_k + \frac h6\big(k_1 + 2k_2 + 2k_3 + k_4\big).$$

For $f$ independent of $x$ this is Simpson's rule from lesson 3, which is a useful way to remember the weights 1, 4, 1 (the 4 split across $k_2$ and $k_3$).

## Accuracy and stability

The local error per step is $O(h^5)$; over $T/h$ steps the global error is $O(h^4)$. Halving the step doubles the cost and cuts the error by 16, which is why RK4 is the default for smooth, non-stiff simulation.

On the test equation $\dot x = \lambda x$, one step multiplies by $1 + z + \tfrac{z^2}{2} + \tfrac{z^3}{6} + \tfrac{z^4}{24}$ with $z = h\lambda$, the Taylor series of $e^z$ to fourth order. For real negative $\lambda$ it is stable for $h|\lambda| < 2.785$, and unlike Euler it covers part of the imaginary axis, $h\omega < 2.828$, so it can integrate undamped oscillators.

## Worked example: one step of ẋ = x

From $x_0 = 1$ with $h = 0.1$:

1. $k_1 = 1$, $k_2 = 1 + 0.05 \times 1 = 1.05$, $k_3 = 1 + 0.05 \times 1.05 = 1.0525$, $k_4 = 1 + 0.1 \times 1.0525 = 1.10525$.
2. $x_1 = 1 + \tfrac{0.1}{6}(1 + 2.1 + 2.105 + 1.10525) = 1.10517083$.
3. Exact: $e^{0.1} = 1.10517092$. The error is $8.5\times10^{-8}$; Euler's would be $5.2\times10^{-3}$.

## Code it from scratch

:::code file=rk4.py
```python
import math
import numpy as np

def rk4_step(f, t, x, u, h):
    k1 = f(t, x, u)
    k2 = f(t + h / 2, x + h / 2 * k1, u)
    k3 = f(t + h / 2, x + h / 2 * k2, u)
    k4 = f(t + h, x + h * k3, u)
    return x + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)

def pendulum(t, x, u, g=9.81, l=1.0):
    return np.array([x[1], -g / l * math.sin(x[0]) + u])

def run(h, t_end=4.0, x0=(1.0, 0.0)):
    """Return θ every 0.1 s, so the error is measured along the whole trajectory."""
    x, out, every = np.array(x0), [], round(0.1 / h)
    for k in range(round(t_end / h)):
        x = rk4_step(pendulum, k * h, x, 0.0, h)
        if (k + 1) % every == 0: out.append(x[0])
    return np.array(out)

if __name__ == "__main__":
    x1 = rk4_step(lambda t, x, u: x, 0.0, np.array([1.0]), 0.0, 0.1)[0]
    assert abs(x1 - 1.10517083) < 1e-8 and abs(x1 - math.exp(0.1) - (-8.5e-8)) < 1e-9
    ref = run(5e-5)                                # 57° swing, so sin θ ≠ θ
    hs = np.array([0.02, 0.01, 0.005, 0.0025])
    errs = np.array([abs(run(h) - ref).max() for h in hs])
    slope = np.polyfit(np.log(hs), np.log(errs), 1)[0]
    print("errors:", errs, f"slope {slope:.3f}")
    assert abs(slope - 4) < 0.1
```
:::end

## Exercises

:::exercise
Write out the RK4 amplification factor for $z = h\lambda = -1$ and compare with $e^{-1}$.
:::solution
$1 - 1 + \tfrac12 - \tfrac16 + \tfrac1{24} = 0.375$. The exact factor is $e^{-1} = 0.3679$, so even at this large step the error is only 2 %.
:::end

:::exercise
An RK4 simulation has a final error of $3.2\times10^{-5}$ at $h = 0.02$ s. What step gives $10^{-7}$?
:::solution
You need a factor of 320. With $O(h^4)$, $h$ shrinks by $320^{1/4} = 4.23$, so $h \approx 0.0047$ s.
:::end
