## Orthonormal columns make least squares trivial

Suppose $A = QR$ where $Q$ has orthonormal columns ($Q^\top Q = I$) and $R$ is upper triangular. Then

$$\lVert A\mathbf x - \mathbf b\rVert^2 = \lVert QR\mathbf x - \mathbf b\rVert^2,$$

and the normal equations $A^\top A\mathbf x = A^\top\mathbf b$ become $R^\top Q^\top Q R\mathbf x = R^\top Q^\top\mathbf b$, which simplifies to

$$R\,\mathbf x = Q^\top \mathbf b .$$

One back substitution, and $A^\top A$ is never formed. Since $Q$ preserves lengths, $\kappa(R) = \kappa(A)$ rather than $\kappa(A)^2$.

## Gram-Schmidt: subtract the shadows

Build $Q$ one column at a time. Take column $\mathbf a_j$, subtract its projection onto every earlier $\mathbf q_i$, and normalise what is left:

$$\mathbf v_j = \mathbf a_j - \sum_{i<j} (\mathbf q_i^\top \mathbf a_j)\,\mathbf q_i, \qquad r_{ij} = \mathbf q_i^\top \mathbf a_j,\quad r_{jj} = \lVert\mathbf v_j\rVert,\quad \mathbf q_j = \mathbf v_j / r_{jj}.$$

Rearranged, $\mathbf a_j = \sum_{i \le j} r_{ij}\mathbf q_i$, which is $A = QR$ column by column.

The classical version computes every $r_{ij}$ from the original $\mathbf a_j$. In floating point the resulting $\mathbf q$'s drift away from orthogonal. The **modified** version subtracts each projection immediately and computes the next coefficient from the updated vector, which is mathematically identical and numerically much better.

### Householder reflections

A Householder reflection $H = I - 2\mathbf v\mathbf v^\top/(\mathbf v^\top\mathbf v)$ mirrors space across the plane perpendicular to $\mathbf v$. Choosing $\mathbf v = \mathbf x + \operatorname{sign}(x_1)\lVert\mathbf x\rVert\mathbf e_1$ maps a column $\mathbf x$ onto a multiple of $\mathbf e_1$, zeroing everything below the diagonal in one step. Applying $n$ reflections gives $H_n\cdots H_1 A = R$, and $Q = H_1 \cdots H_n$ is orthogonal to machine precision. This is what LAPACK does.

## Worked example: Gram-Schmidt by hand

Take the columns $\mathbf a_1 = (1, 1, 0)$ and $\mathbf a_2 = (1, 0, 1)$.

1. $r_{11} = \lVert\mathbf a_1\rVert = \sqrt2 = 1.4142$, $\mathbf q_1 = (0.7071, 0.7071, 0)$.
2. $r_{12} = \mathbf q_1^\top\mathbf a_2 = 0.7071$.
3. $\mathbf v_2 = \mathbf a_2 - 0.7071\,\mathbf q_1 = (0.5, -0.5, 1)$, $r_{22} = \sqrt{1.5} = 1.2247$.
4. $\mathbf q_2 = (0.4082, -0.4082, 0.8165)$. Check: $\mathbf q_1^\top\mathbf q_2 = 0.2887 - 0.2887 + 0 = 0$.

So $R = \begin{pmatrix} 1.4142 & 0.7071 \\ 0 & 1.2247\end{pmatrix}$.

## Code it from scratch

:::code file=qr.py
```python
import numpy as np

def mgs(A):
    A = np.array(A, float); m, n = A.shape
    Q, R = np.zeros((m, n)), np.zeros((n, n))
    V = A.copy()
    for j in range(n):
        R[j, j] = np.linalg.norm(V[:, j])
        Q[:, j] = V[:, j] / R[j, j]
        for k in range(j + 1, n):              # subtract the projection immediately
            R[j, k] = Q[:, j] @ V[:, k]
            V[:, k] -= R[j, k] * Q[:, j]
    return Q, R

def householder_qr(A):
    R = np.array(A, float); m, n = R.shape
    Q = np.eye(m)
    for k in range(n):
        x = R[k:, k]
        v = x.copy(); v[0] += np.copysign(np.linalg.norm(x), x[0])
        if np.linalg.norm(v) == 0: continue
        v /= np.linalg.norm(v)
        R[k:, :] -= 2 * np.outer(v, v @ R[k:, :])
        Q[:, k:] -= 2 * np.outer(Q[:, k:] @ v, v)
    return Q[:, :n], R[:n]

def back(R, y):
    x = np.zeros(len(y))
    for i in reversed(range(len(y))):
        x[i] = (y[i] - R[i, i + 1:] @ x[i + 1:]) / R[i, i]
    return x

if __name__ == "__main__":
    Q, R = mgs([[1, 1], [1, 0], [0, 1]])
    assert np.allclose(R, [[2 ** .5, 2 ** -.5], [0, 1.5 ** .5]])
    rng = np.random.default_rng(5)
    A = rng.standard_normal((50, 8))
    for Q, R in (mgs(A), householder_qr(A)):
        assert np.allclose(Q.T @ Q, np.eye(8), atol=1e-12) and np.allclose(Q @ R, A)
    # ill-conditioned fit: degree-11 polynomial on [0, 1]
    t = np.linspace(0, 1, 60)
    V = np.vander(t, 12, increasing=True)
    c_true = rng.standard_normal(12)
    b = V @ c_true
    Q, R = householder_qr(V)
    c_qr = back(R, Q.T @ b)
    c_ne = np.linalg.solve(V.T @ V, V.T @ b)
    e_qr = np.linalg.norm(c_qr - c_true) / np.linalg.norm(c_true)
    e_ne = np.linalg.norm(c_ne - c_true) / np.linalg.norm(c_true)
    print(f"cond(V) = {np.linalg.cond(V):.1e}; error QR {e_qr:.1e}, normal equations {e_ne:.1e}")
    assert e_qr < 1e-4 and e_ne > 100 * e_qr
```
:::end

On this fit $\kappa(V) \approx 10^{8}$. QR recovers the coefficients to about $10^{-8}$, while the normal equations, working with $\kappa \approx 10^{16}$, lose almost every digit.

3. $r_{22} = 0.8$, $\mathbf q_2 = (0.8, -0.6)$. Check $\mathbf q_1^\top\mathbf q_2 = 0.48 - 0.48 = 0$.
:::end

:::exercise
Why does the Householder vector use $+\operatorname{sign}(x_1)\lVert\mathbf x\rVert$ rather than the minus sign?
:::solution
Using the same sign as $x_1$ means the first entry of $\mathbf v$ is a sum of two numbers with the same sign. With the opposite sign, when $\mathbf x$ is nearly parallel to $\mathbf e_1$ you subtract two almost equal numbers and lose precision (cancellation).
:::end
